# My Pace

**A little better, every day.**

My Pace is a personal habit tracker built with React + Vite. It focuses on keeping a sustainable pace without punishment, negative XP, or streak pressure.

## v1.0

- Daily Quests (3–5 configurable goals)
- Weekly Special Quest
- 28-day Pace Score
- Category Pace
- XP / Level progression
- Recent activity heatmap
- Light / Dark mode
- Local browser persistence
- PWA manifest

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
